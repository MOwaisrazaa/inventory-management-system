⚙️  INSTALLATION COMMANDS

WINDOWS:
  1. Extract PHP to: C:\php
  2. Add to PATH: C:\php
  3. Install Composer: Run Composer-Setup.exe
  4. Install MySQL: Run MySQL installer
  5. Start MySQL: Services → MySQL80 → Start

LINUX/MAC:
  brew install php@8.2
  brew install composer
  brew install mysql
  brew services start mysql

🚀 LARAVEL SETUP

cd inventory-app
composer install
copy .env.example .env
php artisan key:generate

Edit .env:
  DB_DATABASE=inventory_db
  DB_USERNAME=root
  DB_PASSWORD=

mysql -u root -p
CREATE DATABASE inventory_db;
EXIT;

php artisan migrate
php artisan serve

Open: http://localhost:8000

🐛 QUICK FIXES

"php not recognized"
  → Add C:\php to PATH
  → Restart Command Prompt

"composer not recognized"
  → Reinstall Composer
  → Restart Command Prompt

"MySQL error"
  → Start MySQL service
  → Check .env credentials

"Port 8000 in use"
  → php artisan serve --port=8001

"Key not generated"
  → php artisan key:generate
