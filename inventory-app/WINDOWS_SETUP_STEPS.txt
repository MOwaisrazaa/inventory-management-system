STEP 1: PHP INSTALL KARO (5 MINUTES)
════════════════════════════════════════════════════════════════════════════

1. Browser kholo aur jao: https://www.php.net/downloads.php

2. "Windows downloads" section mein dekho

3. "VS16 x64 Non Thread Safe" download karo
   - File name: php-8.2.x-nts-Win32-vs16-x64.zip (ya 8.3)
   - Size: ~50-60 MB

4. Downloaded file ko extract karo:
   - Right-click → "Extract All"
   - Destination: C:\php
   - Extract button click karo

5. Environment Variable add karo:
   a) Windows key + X dabao
   b) "System" click karo
   c) "Advanced system settings" click karo
   d) "Environment Variables" button click karo
   e) "Path" variable select karo
   f) "Edit" button click karo
   g) "New" button click karo
   h) Type karo: C:\php
   i) "OK" click karo (3 baar)

6. Verify karo:
   - Command Prompt kholo (Win + R → cmd → Enter)
   - Type karo: php --version
   - Output: PHP 8.x.x dikhna chahiye ✓

════════════════════════════════════════════════════════════════════════════

STEP 2: COMPOSER INSTALL KARO (5 MINUTES)
════════════════════════════════════════════════════════════════════════════

1. Browser kholo aur jao: https://getcomposer.org/download/

2. "Composer-Setup.exe" download karo
   - Size: ~5 MB

3. Downloaded file ko double-click karo

4. Installation wizard khul jayega:
   a) "Next" button click karo
   b) PHP path select karo: C:\php\php.exe
   c) "Next" click karo
   d) "Install" button click karo
   e) Installation complete hone ka wait karo (2-3 minute)

5. Verify karo:
   - Command Prompt kholo
   - Type karo: composer --version
   - Output: Composer version x.x.x dikhna chahiye ✓

════════════════════════════════════════════════════════════════════════════

STEP 3: MYSQL INSTALL KARO (5 MINUTES)
════════════════════════════════════════════════════════════════════════════

1. Browser kholo aur jao: https://dev.mysql.com/downloads/mysql/

2. "MySQL Community Server" download karo
   - Latest version select karo
   - Size: ~300-400 MB

3. Downloaded file ko double-click karo

4. Setup wizard khul jayega:
   a) "Setup Type" → "Developer Default" select karo
   b) "Next" click karo
   c) Installation complete hone ka wait karo (5-10 minute)

5. MySQL Configure karo:
   a) "MySQL Server 8.0.x" select karo
   b) "Next" click karo
   c) "Standalone MySQL Server" select karo
   d) "Next" click karo
   e) Port: 3306 (default)
   f) "Next" click karo
   g) "MySQL Server as a Windows Service" check karo
   h) Service name: MySQL80 (default)
   i) "Next" click karo
   j) "Execute" click karo
   k) Configuration complete hone ka wait karo

6. MySQL Start Karo:
   a) Services app kholo (Win + R → services.msc → Enter)
   b) "MySQL80" find karo
   c) Right-click → "Start" karo
   d) Status: "Running" dikhna chahiye ✓

STEP 4: LARAVEL PROJECT SETUP KARO (5 MINUTES)
════════════════════════════════════════════════════════════════════════════

1. Command Prompt kholo

2. Project folder mein jao:
   cd inventory-app

3. Dependencies install karo:
   composer install
   (Wait karo 2-3 minute)

4. Environment file create karo:
   copy .env.example .env

5. Application key generate karo:
   php artisan key:generate

6. .env file edit karo:
   a) .env file kholo (Notepad mein)
   b) Yeh lines find karo:
      DB_CONNECTION=mysql
      DB_HOST=127.0.0.1
      DB_PORT=3306
      DB_DATABASE=inventory_db
      DB_USERNAME=root
      DB_PASSWORD=
   c) File save karo

7. Database create karo:
   a) Command Prompt mein type karo:
      mysql -u root -p
   b) Password enter karo (agar set kiya hai, nahi toh Enter dabao)
   c) Yeh command type karo:
      CREATE DATABASE inventory_db;
   d) Type karo:
      EXIT;

8. Migrations run karo:
   php artisan migrate
   (Wait karo jab tak complete na ho)

9. Server start karo:
   php artisan serve
   
   Output dikhna chahiye:
   "Server running at http://127.0.0.1:8000"

10. Browser kholo aur jao:
    http://localhost:8000
    
    Dashboard page load hona chahiye! ✓

🐛 COMMON ISSUES

ISSUE: "php is not recognized"
FIX: Environment Variables mein C:\php add karo aur Command Prompt restart karo

ISSUE: "composer is not recognized"
FIX: Composer installer dobara install karo aur Command Prompt restart karo

ISSUE: "SQLSTATE[HY000]: General error: 1030"
FIX: MySQL running hai check karo (Services mein)

ISSUE: "Port 8000 already in use"
FIX: php artisan serve --port=8001

ISSUE: "No application encryption key"
FIX: php artisan key:generate
