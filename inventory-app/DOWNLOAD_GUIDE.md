## ⚠️ Important Notes

### PHP Version Selection

**NTS (Non Thread Safe) vs TS (Thread Safe):**
- **NTS** = Better performance, use with FastCGI
- **TS** = Better compatibility, use with Apache
- **Recommendation:** NTS (for development)

**x64 vs x86:**
- **x64** = 64-bit (Recommended for modern systems)
- **x86** = 32-bit (Older systems)
- **Recommendation:** x64

**VC16 vs VC17:**
- **VC16** = Visual C++ 2019 (Stable)
- **VC17** = Visual C++ 2022 (Newer)
- **Recommendation:** VC16 (more compatible)

### MySQL Version Selection

**8.0.x vs 5.7.x:**
- **8.0.x** = Latest, better performance
- **5.7.x** = Older, still supported
- **Recommendation:** 8.0.x
