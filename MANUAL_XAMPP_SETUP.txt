🐛 TROUBLESHOOTING

PROBLEM: Installation nahi ho raha
SOLUTION:
  1. Administrator mode se run karo
  2. Antivirus disable karo (temporarily)
  3. Firewall check karo
  4. Disk space check karo (500MB+ chahiye)

PROBLEM: Apache start nahi ho raha
SOLUTION:
  1. Port 80 already in use hai
  2. XAMPP Control Panel → Apache → Config → httpd.conf
  3. Find: Listen 80
  4. Change to: Listen 8080
  5. Apache restart karo

PROBLEM: MySQL start nahi ho raha
SOLUTION:
  1. XAMPP Control Panel → MySQL → Admin
  2. phpMyAdmin khul gaya toh MySQL running hai
  3. Nahi toh MySQL restart karo
